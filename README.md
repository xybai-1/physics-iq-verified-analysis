# Physics-IQ Verified Interactive Failure Analysis

Interactive case-level review of 198 Physics-IQ Verified videos across 66 scene families.

The website includes:

- PASS / FAIL annotation controls
- twelve predefined multi-label failure categories
- prompt, input frame, output timeline, and playable video for every case
- official baseline, PhaseLock, and delta scores
- live distribution charts and filters
- browser-local persistence with JSON and CSV export

Open `index.html` or visit the repository's GitHub Pages deployment.

## Data note

Annotations edited in the website are stored in the visitor's browser until exported. The checked-in CSV and JSON files contain the initial manual-review dataset.
